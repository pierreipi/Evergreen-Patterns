Fail Fast

April 18, 2022

Principle

Before starting a task ensure it has a chance to complete. A chef won’t start to cook before he ensured he has all the ingredients

Fail-fast systems are designed to stop operation rather than attempting to continue a possibly flawed process. Eases debugging, improves visibility and understanding of root causes

Implemented in circuit breakers When a circuit status in « Open »: solicitations instantly fail

Examples

  • Input validation
    • We validate user input before we submit to a server
    • If required data is missing, we do not try to execute the process
    • Applicable to any kind of validation (uploaded data files, logistic network description, …)
  • Especially before long running operations
    • Do not generate a big data file before checking that the destination is online for instance
    • …
